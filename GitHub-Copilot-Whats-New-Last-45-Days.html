VII.Copilot code review08

VIII.Enterprise governance09

Policy follows the agent.

Managed controls now span more clients, teams, models, plugins, MCP servers, telemetry, and permission modes.

Global model policy GA

Unconfigured GA models can dynamically inherit the default policy; explicit model decisions are preserved.

Safer defaults

Open-weight models and models requiring data retention remain disabled by default.

Team specialization

Approved team overrides can tailor settings while preserving the enterprise baseline.

Cross-client enforcement

Controls reach VS Code, CLI, Copilot app, cloud agent, and JetBrains.

26 Aug · Global model policy GA · 3 Aug · Team specialization

IX.MCP + managed settings10
